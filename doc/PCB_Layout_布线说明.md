# JMGatt 语音马桶控制器 PCB Layout 布局布线说明（最终版）

> 适用硬件：ESP32-WROOM-32E + ASRPRO-CORE-4M，SY8089A1AAC 电源方案  
> 板层数：双层板，1.6mm，FR-4，1oz 铜（35µm）  
> Type-C：6P 母座，仅供电  
> 最终版硬性修改：ASR-PRO 由 5V 供电；U4 EN 上拉到 5V；删除 U6 外接功放；F1 改 1.5A；FB1 改 1A；R13/R17 改 0Ω 或 33Ω

---

## 一、设计总原则

本板核心矛盾：**ESP32 的 WiFi/BLE 射频突发 vs ASR-PRO 的音频小信号**。所有布局布线围绕“让射频干扰和电源纹波进不了音频通路”展开：

1. 分区布局：数字区（供电/ESP32）与音频区（ASR-PRO/麦克风/喇叭）物理隔离。
2. 完整地平面：底层全部铺 GND，禁止分割。
3. 电源先过滤波再进音频区：π 型滤波（FB1 + C11 + C12）是杂音抑制的生命线。
4. 大电流环路最小化：DC-DC 的 SW 环路、ESP32 的 3.3V 供电路径都要短而粗。
5. 无板载 USB 转串口：J1 Type-C 仅供电，烧录通过 J3/J4 焊盘外接 USB-TTL。

## 三、各模块布局要点

### 3.1 供电区（Type-C + SY8089A1AAC）
- J1 放板边，6P 母座注意板边开槽尺寸；只焊 VBUS/GND/CC 相关引脚，D+/D- 不接。
- R1/R2（CC 下拉）紧贴 J1 的 CC 引脚，两个都要焊（兼容 C-to-C 线取电）。
- F1 串联在 VBUS 主路径，C1/C2 靠近 F1 之后。
- DC-DC 按“输入→开关→输出”一字排开：
5V ──→ [C3 10µF] ──→ VIN ┌──────┐ SW ──→ [L1 2.2µH] ──→ 3.3V ──→ [C4 22µF + C5 100nF]
│ U4 │ │
│ EN │ GND────────────────────┘
└──────┘
│
R7 100kΩ → 5V

- C3 紧贴 U4 VIN，C4/C5 紧贴 VOUT，L1 紧贴 SW 脚。
- SW 节点（U4-SW → L1 → C4）环路面积最小化，SW 走线短而宽（≥20mil），下方底层保持完整地。
- 整个电源区远离麦克风走线和 ASR-PRO 模组 ≥10mm。
- **U4 EN 必须通过 R7 100kΩ 上拉到 5V，不能悬空，也不能上拉到 3.3V 输出。**

### 3.2 ESP32 区
- 天线朝板边，最好让模组天线端伸出板外；天线正下方及板外 5mm 范围内双面禁铺铜。
- 天线方向远离 ASR-PRO、麦克风、喇叭口——这是本板最关键的射频隔离。
- C7/C8 紧贴模组 3V3 供电脚；R5（GPIO12 下拉）靠近模组对应引脚。
- SW1/SW2 放板边顺手位置（没有自动下载电路后，这两个按键是进下载模式的唯一手段，必须好按）。
- J4 下载焊盘（EN/IO0/TX0/RX0/3V3/GND 共 6 个）放板边靠近 SW1/SW2：
  - TX0/RX0 焊盘走线到 GPIO3/GPIO1 短直。
  - 焊盘间距 2.54mm，可焊排针，丝印明确标注每个焊盘信号名。
  - 外接 USB-TTL 烧录接线：TTL-TX→RX0、TTL-RX→TX0、GND→GND（3V3/EN/IO0 一般不用接）。

### 3.3 ASR-PRO 音频区（杂音抑制核心）
- 供电进线顺序：5V → R15 0Ω → FB1（磁珠）→ C11（470µF）+ C12（100nF）→ U2 Pin17，三者紧贴 Pin17 依次排开，路径上不允许有分叉。
- C13（4.7µF）紧贴 Pin1（3V3 脚）。
- MIC1 紧贴 ASR-PRO 的 MIC 输入脚，R11/C9/C10 围绕 MIC1 就近放置，麦克风走线全程两侧包地。
- MIC1 拾音孔方向避开喇叭（防啸叫/回声，装配时也注意腔体）。
- J2（喇叭口）走线加粗到 ≥40mil（约1mm），载流按 1A 设计。
- U5 备用供电轨已删除/不焊；R15 默认焊接，5V 经 FB1 直供 Pin17。
- J3 ASR 烧录口（PB5/PB6/PA4/5V/GND）放板边，走线短直；天问Block 烧录时外接 USB-TTL 到 PB5/PB6。

### 3.4 串口互联（ESP32 ↔ ASR-PRO）
- 两根线：U1-GPIO17 ← R12/R13 ← PA2-U2；U1-GPIO16 → R16/R17 → PA3-U2。
- 每线只保留一个源端 100Ω，另一端建议 0Ω 或 33Ω：
  - R12 100Ω 靠近 ASR-PRO TX 端；R13 0Ω 或 33Ω 靠近 ESP32 RX 端。
  - R16 100Ω 靠近 ESP32 TX 端；R17 0Ω 或 33Ω 靠近 ASR-PRO RX 端。
- 串口线不要长距离与 SW 节点、天线方向平行。

## 四、电源树与走线宽度

| 网络 | 路径 | 建议线宽 | 说明 |
|---|---|---|---|
| VBUS 5V | J1 → F1 → 5V 轨 | ≥40mil (1mm) | 全板 5V 主干 |
| 5V → ASR-PRO | 5V → R15 → FB1 → C11 → U2 Pin17 | ≥20mil (0.5mm) | π 滤波路径 |
| 3.3V 主干 | U4 → C4 → ESP32 模组 | ≥60mil (1.5mm) | WiFi 峰值电流 500mA |
| 3.3V 支线 | 至上拉电阻/LED 等 | 10~15mil | 小电流 |
| SW 节点 | U4-SW → L1 | ≥20mil | 短且粗 |
| GND | 全部 | 底层整层铺铜 | 见地处理一节 |
| 喇叭线 | U2 SPKL± → J2 | ≥40mil (1mm) | 载流 1A |
| 下载口线 | J4 → GPIO1/3，J3 → PB5/PB6 | 10mil | 短直 |

## 五、地平面处理（关键）

1. 底层（Bottom）整层铺 GND，完整不分割。双层板上分割地平面弊大于利，模拟/数字隔离靠“布局分区 + 就地退耦”实现。
2. 顶层（Top）在空白区域也铺 GND，与底层通过过孔缝合（每 300~500mil 一个，区域边缘加密）。
3. 每个芯片的去耦电容接地端就近打接地过孔到底层 GND，过孔紧贴焊盘。
4. U4 的 GND 脚、ESP32 模组底部散热焊盘：多打过孔到底层。
5. 天线净空区除外——天线下方双面禁铜。

## 六、关键信号布线规则

| 信号 | 规则 |
|---|---|
| SW 节点 | 最短路径，不走底层（避免跨分割），下方保持完整 GND 参考 |
| UART（ESP32↔ASR-PRO） | 每线源端串 100Ω，另一端 0Ω/33Ω，不与音频线平行走 >10mm |
| 下载口走线 | J4→GPIO1/3、J3→PB5/PB6 短直，焊盘丝印标注信号名 |
| MIC 走线 | 全程两侧 GND 包地（via 缝合），长度尽量 <15mm |
| SPK 喇叭线 | ≥40mil 粗线，短直，不绕行 |
| EN / BOOT | 按键线普通 8mil 即可，注意上拉/下拉电阻位置 |
| 天线净空 | 模组天线段伸出板边或板边留 ≥5mm 双面禁铜区 |

## 七、铺铜、丝印与 DFM

- 顶层/底层默认 GND 铺铜，与焊盘间距 10mil，大铜皮加散热十字连接（电源焊盘直连，信号焊盘十字）。
- 过孔规格：孔 0.3mm / 盘 0.6mm；电源路径过孔按 ≥2 个并联。
- 最小线宽/线距：6/6mil（本项目无 BGA，轻松满足）。
- 丝印：位号不压焊盘；J2/J3/J4 标注 Pin1 和每个焊盘信号名；标注 PA2/PA3 ↔ GPIO16/17 对应关系；板名+版本号+日期放显眼处。
- 安装孔：四角 M3（Φ3.2mm）非金属化，离板边 ≥5mm。
- 打样前输出 Gerber 检查：确认天线禁铜区、FB1→C11 路径无分叉、底层 GND 完整。

## 八、烧录流程（无板载串口）

### ESP32 烧录（J4 + 外接 USB-TTL）
1. USB-TTL 接 J4：TTL-TX→RX0、TTL-RX→TX0、GND→GND（共地）。
2. 进下载模式：按住 SW2(BOOT) → 点按 SW1(RST) → 松开 SW2。
3. `idf.py -p COMx flash` 烧录，完成后点按 SW1 复位运行。
4. USB-TTL 用 3.3V 电平款（或 TTL 设 3.3V 档）；ESP32 的 GPIO1/3 是调试口，`idf.py monitor` 也从这里看日志。

### ASR-PRO 烧录（J3 + 外接 USB-TTL）
1. USB-TTL 接 J3：TTL-TX→PB5、TTL-RX→PB6、GND→GND（具体收发对应关系以天问原理图为准）。
2. 天问Block 点“编译下载”，按提示复位/上电模块。
3. J3 的 5V 焊盘不要接 USB-TTL 的 5V（板子由 J1 供电），只接信号和 GND。

## 九、回流焊曲线（折中）

- ASR-PRO 要求 Tp≥260°C，ESP32 推荐峰值 235~250°C。
- 建议折中曲线：
  - 预热：150~200°C，60~120s
  - 回流：>217°C，60~90s
  - 峰值：245~250°C
  - 冷却：-1~-5°C/s
- 只过一次回流焊，投板前和 ASR-PRO 供应商确认。

## 十、投产前检查清单

**DRC：**
- [ ] 无短路/断路，间距违规清零
- [ ] 所有网络已连接
- [ ] 天线区双面禁铜确认

**自查（杂音抑制相关，逐条核对）：**
- [ ] U5 已删除/不焊，ASR-PRO 确认由 5V 供电
- [ ] R7 100kΩ 已加，U4 EN 上拉到 5V
- [ ] ESP32 EN 的 R3/C6/SW1 正确
- [ ] U6/C16~C18 已删除/不焊，SPK+/- 只接 J2 喇叭
- [ ] FB1 为 1A 规格，C11 为低 ESR 470µF
- [ ] F1 为 1.5A/6V
- [ ] R13/R17 改为 0Ω 或 33Ω，避免每线 200Ω
- [ ] FB1→C11(470µF)→C12(100nF)→Pin17 路径连续、紧贴、无分叉
- [ ] C11 用了低 ESR 钽/聚合物（不是普通电解）
- [ ] MIC1 紧贴 U2，麦克风线包地且远离天线/SW
- [ ] ESP32 天线方向背离音频区
- [ ] SW 环路面积目视最小
- [ ] 底层 GND 无分割
- [ ] J2 喇叭线 ≥40mil
- [ ] J3/J4 焊盘丝印信号名齐全、都在板边

**功能验证（板回来后）：**
- [ ] J1 供电：5V/3.3V 电压正常，SY8089 无异常发热
- [ ] J4 + SW1/SW2 可进 ESP32 下载模式并烧录成功
- [ ] J3 可烧录 ASR-PRO
- [ ] 说唤醒词 → ESP32 日志出现 WAKE → 马桶连接 → 喇叭播报“已连接”
- [ ] 待机 10 分钟听喇叭底噪
- [ ] WiFi 连接 + BLE 扫描同时工作时再次听底噪

## 十一、遗留风险与对策

| 风险 | 现象 | 对策 |
|---|---|---|
| 杂音仍残留 | 待机底噪可闻 | 优化 FB1+C11+C12 路径，确认 C11 低 ESR；不要改 3.3V 供电 |
| 喇叭音量不足 | ASR-PRO 内置功放推 2W 喇叭偏小 | 换高灵敏度带腔体喇叭；若必须外接功放，需确认 ASR-PRO 有 Line out |
| WiFi 吞吐差 | 信号弱 | 检查天线净空，确认模组天线伸出板边 |
| 播报时重启 | ASR-PRO 播报电流冲击拉垮 5V | 确认 C11 是低 ESR 且紧贴 Pin17 |
| 烧录不稳 | ESP32 下载报错 | 换短杜邦线、确认共地、SW2 按法正确 |
