## 一、系统架构

```
                          ┌─────────────────────────────────────────┐
                          │              自定义 PCB                  │
                          │                                          │
  Type-C 5V ──[ESD]──┬──> 5V 主轨 ──┬──> ASRPRO-CORE (5V直供)        │
                     │              ├──> CH340C (USB转串口)          │
                     │              └──> 3.3V LDO ──> ESP32-WROOM-32E │
                     │                                               │
                     └── USB D+/D- ──> CH340C ──UART0──> ESP32 GPIO1/3│
                                          └──自动下载──> EN / GPIO0   │
                          │                                          │
                          │  ESP32 GPIO16(TX) ──> ASR-PRO PA3(RX)    │
                          │  ESP32 GPIO17(RX) <── ASR-PRO PA2(TX)    │
                          └─────────────────────────────────────────┘
                                     │              │
                                  [麦克风]        [喇叭]
```

三大功能块：
1. **ESP32-WROOM-32E**：主控 + BLE，连接马桶
2. **ASRPRO-CORE**：离线语音识别，麦克风拾音、喇叭播报
3. **CH340C + Type-C**：供电 + ESP32 烧录

## 二、电源树与电流预算

### 电源树

```
Type-C VBUS (5V)
   │
   ├──[F1 保险丝]──[防反接]──> +5V 主轨
   │                            │
   │                            ├──> ASRPRO-CORE Pin17 (5V)   峰值 250mA
   │                            ├──> CH340C VCC (5V)          ~20mA
   │                            └──> U4 LDO AMS1117-3.3
   │                                     └──> +3.3V ──> ESP32-WROOM-32E  峰值~250mA
   │
   └── (ASR-PRO 内部 LDO) Pin1 输出 3.3V/10mA ──> 仅供内部，不外带
```

### 电流预算（5V 主轨）

| 负载 | 典型 | 峰值 | 备注 |
|---|---|---|---|
| ASR-PRO 播报 | 40mA | 250mA | 8Ω2W喇叭，规格书NOTE2 |
| ESP32 BLE发送（经LDO折算5V） | 60mA | ~180mA | BLE峰值低于WiFi |
| CH340C | 15mA | 20mA | |
| **合计** | **~115mA** | **~450mA** | |

**结论**：Type-C 默认 USB2.0 供 500mA，峰值余量偏小。**建议使用 5V/1A 以上电源适配器**，并保证 5V 主轨有 ≥100μF 储能电容，应对播报瞬间的电流冲击。

## 四、引脚连接表

### 4.1 ESP32 ↔ ASR-PRO 通信（UART1，3.3V电平直连，**双向**）

| ESP32-WROOM-32E | 方向 | ASRPRO-CORE | 用途 |
|---|---|---|---|
| GPIO16（Pin27，U2TXD） | ESP32 TX → | PA3（Pin4，UART1_RX） | **语音反馈**（ESP32回传状态码，必需） |
| GPIO17（Pin28，U2RXD） | ← ASR TX | PA2（Pin5，UART1_TX） | **语音命令**（ASR-PRO发命令帧） |
| GND（Pin1/15/38） | 共地 | GND（Pin18） | — |

> **两根信号线都必需**：GPIO17←PA2 收语音命令，GPIO16→PA3 发语音反馈（“已连接”“已打开脚感”等）。早期版本 TX 可省，加入语音反馈后必须连接。

## 五、关键设计注意事项

### ① GPIO16/17 与 PSRAM 冲突（最重要）

ESP32-WROOM-32E 的 **R2 变体（N4R2/N8R2/N16R2）内置 PSRAM，会占用 GPIO16/17**！
本项目 UART2 正好使用 GPIO16/17。

- ✅ **必须选不带 PSRAM 的型号**：`ESP32-WROOM-32E-N4` / `-N8` / `-N16`
- ❌ 不要用 `-N4R2` / `-N8R2` / `-N16R2`
- 若已购 R2 版本，需将 UART 改到其他引脚（如 GPIO25/26），并在 `idf.py menuconfig` 中修改 `ASR_UART_RX_PIN` / `ASR_UART_TX_PIN`

### ② ESP32 Strapping 引脚（上电电平敏感）

| 引脚 | 上电要求 | 处理 |
|---|---|---|
| GPIO12（MTDI） | **必须为低** | 禁止上拉！加 10kΩ 下拉（R5），拉高会设成1.8V Flash无法启动 |
| GPIO0 | 高=运行，低=下载 | 10kΩ 上拉（R4）+ BOOT 按键到 GND |
| GPIO2 | 低或悬空 | 悬空即可 |
| GPIO15（MTDO） | 影响启动日志 | 悬空 |

### ③ ESP32-WROOM-32E 天线 Keepout（PCB天线版）

- 模组天线区域**下方禁止铺铜、走线、放置元件**
- 按数据手册图10（ESP32-WROOM-32E Land Pattern）留出天线净空区
- 模组放置在**板边**，天线朝向板外，远离金属/屏蔽罩

### ④ EPAD 接地散热

- 模组底部焊盘（Pin39 EPAD）**必须接 GND**
- 打多个热过孔（thermal via）连接到底层地平面，增强散热和接地

### ⑤ ASR-PRO 供电（大电流脉冲，规格书NOTE2）

- 5V 供电，播报峰值 250mA，**必须提供 ≥500mA 驱动能力**
- 5V 入口放 **≥100μF** 大电容（C11），否则播报瞬间电流冲击导致模块复位/串口掉线
- **Pin1（3V3 内部LDO输出）必须外接 4.7μF 电容（C13）**，且对外供电不超过 10mA
- 建议用独立 LDO 供电，DC-DC 纹波需 <30mV

### ⑥ 麦克风/喇叭布局（影响识别率）

- 麦克风走线**尽量短并做屏蔽**，远离喇叭和电源线
- 喇叭走线**短而粗**，该区域不得有其他走线跨越
- 麦克风与喇叭**物理分开**布置，减少声学串扰（回声消除依赖布局）
- 推荐麦克风：灵敏度 -32±3dB，信噪比 ≥65dB
- 推荐喇叭：带腔体的 8Ω 2W 喇叭

### ⑦ 电平兼容

- ESP32 与 ASR-PRO 均为 3.3V UART
- ASR-PRO UART 支持 5V 宽压直连
- 两者**可直接连接**，无需电平转换芯片

### ⑧ 烧录注意事项

- ESP32：通过 Type-C + CH340C + 自动下载电路，`idf.py flash` 一键烧录
- ASR-PRO：通过 J3 排针接 STC-LINK 烧写器，PA4 拉高进编程模式，用天问烧写软件

## 六、PCB 布局建议

```
┌──────────────────────────────────────────────┐
│  [天线Keepout净空区]                           │  ← 板边，天线朝外
│  ┌─────────────┐                              │
│  │ ESP32-      │        ┌──────────────┐      │
│  │ WROOM-32E   │        │  ASRPRO-CORE │      │
│  │  (U1)       │  UART  │    (U2)      │      │
│  └─────────────┘◄──────►└──────────────┘      │
│         │              MIC○        ○SPK        │
│    ┌────┴────┐         │           │          │
│    │ CH340C  │      [麦克风]     [喇叭接口]     │
│    │  (U3)   │        远离喇叭、屏蔽走线         │
│    └────┬────┘                                 │
│   Type-C┘   [LDO U4]   [100μF储能]             │
└──────────────────────────────────────────────┘
     ↑供电/烧录口          ↑电源区集中布置
```

**布局要点：**

1. **天线区**：ESP32 模组放板边，天线朝外，天线下方及周围留净空区（无铜、无线、无元件）
2. **电源区**：Type-C、LDO、大电容集中在板一角，缩短大电流路径
3. **模拟区隔离**：麦克风电路远离喇叭、电源线、DC-DC 电感
4. **数字通信**：ESP32 与 ASR-PRO 的 UART 走线短直，串联电阻就近放置
5. **接地**：数字地与功率地在电源入口单点汇接，大面积铺地
6. **去耦电容**：每个 IC 电源脚就近放 100nF + 10μF
7. **喇叭/麦克风连接器**：放板边，方便外接

## 附：设计核对清单（Checklist）

- [ ] ESP32 模组选型**不带 PSRAM**（GPIO16/17 可用）
- [ ] GPIO12 有下拉或悬空（绝不上拉）
- [ ] GPIO0 有上拉 + BOOT 按键
- [ ] EN 有 RC 复位电路（10kΩ + 1μF）
- [ ] Type-C CC1/CC2 各接 5.1kΩ 下拉
- [ ] USB D+/D- 有 ESD 保护
- [ ] 5V 主轨有 ≥100μF 储能电容
- [ ] ASR-PRO Pin1（3V3）外接 4.7μF
- [ ] ESP32 天线区 Keepout 净空
- [ ] ESP32 EPAD 接地 + 散热过孔
- [ ] 麦克风远离喇叭，走线短且屏蔽
- [ ] 所有电阻电容 0603 封装（大电容除外）
- [ ] 预留 5V/3.3V/GND/UART 测试点
