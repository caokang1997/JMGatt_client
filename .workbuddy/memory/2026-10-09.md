## 蓝牙语音智能马桶控制器 — PCB 方案规划 + BOM

### 背景
项目 JMGatt_client：ESP32-WROOM-32E + 天问 ASRPRO-CORE 语音模块，BLE 控制九牧 SQ9650 智能马桶。
软硬件开发板已联调通过，本次任务为 PCB 落地规划。

### 现有设计要点（从 README/源码/规格书梳理）
- 主控：ESP32-WROOM-32E（18×25.5×3.1mm，3.0-3.6V，板载PCB天线，4MB Flash）
- 语音：ASRPRO-CORE-2M（18×23×2.9mm，SMD-18，供电 3.6-5V，峰值 500mA，内置SSOP24）
- 电源：SY8089A1AAC（SOT23-5，VIN 2.5-5.5V，IOUT 2A，1.5MHz，VFB=0.6V）
- 引脚：ESP32 GPIO19(RX)/GPIO18(TX) ↔ ASR PA2/PA3，115200 8N1，帧 AA 55 CMD 00 55
- 反馈：ESP32→ASR 单字节 0xB1~0xBC 触发语音播报
- 复位：长按 GPIO0(BOOT) 5s 清配网；烧录 UART0

### 关键设计决策
1. **双电源轨**：ASRPRO 最小 3.6V，不能用 SY8089 的 3.3V 供电 → 5V(VBUS直通)给 ASRPRO+功放，
   3.3V(SY8089降压)给 ESP32。规格书明确提示。
2. SY8089 设 3.3V：RL=100k，RH=450k（Vout=0.6×(1+RH/RL)）。
3. 4 层板：L1信号/L2完整地/L3电源/L4信号；板框约 55×45mm。

### 约束落实情况
- **喇叭远离 ESP32 天线**：喇叭置板对角远端（≥25mm），SPK 走线短粗、禁跨越、远离天线净空区；
  天线正下方全层掏空，板边 15mm 净空。
- Type-C 6pin 输入：VBUS→PPTC→TVS→DC-DC；CC1/CC2 各 5.1kΩ 下拉。

### 变更 Rev1.0 → Rev1.1（用户要求：不外加功放）
- 音频改用 **ASRPRO 内置 8002A 功放**：SPKL−(pin8)/SPKL+(pin9) 直接驱动喇叭（BTL，无需输出隔直电容）；
  MUTE(pin12) 为使能，低有效，模组默认使能，可选接 PA4(pin13) 做软件静音。
- 从 BOM 移除：外置功放 U4(LM4990/PAM8302A)、C13 输入耦合、C14 功放电源去耦、C15 输出隔直电容、R7 增益电阻。
- 新增：FB1 SPK 输出磁珠(可选,2pcs)、TVS3 喇叭 ESD。SP1/J2 保留，改为“由内置功放直接驱动”。
- 5V 轨峰值电流由 ~1.05A 降至 ~0.25A，电源滤波压力显著减小；VBUS 仍需 ≥100µF 储能电容。
- 音频区不再含独立功放芯片，更易满足“喇叭远离天线”隔离要求（喇叭置于板对角远端，与天线≥25mm）。
- 物料数量：42项/52pcs → 39项/51pcs。

### 追加：固件烧录与下载操作流程（docx）
- 文件：固件烧录与下载操作流程.docx（+ 对话内联双通道流程图）
- 核心事实（ASRPRO 规格书 §8 + 官方应用电路）：
  · ASRPRO 烧录口 = **UART0：PB5(pin16)=TX0、PB6(pin15)=RX0**，与跟 ESP32 通信的 UART1(PA2/PA3) 是两组独立串口
    → 板上烧录 ASRPRO 不需断开任何与 ESP32 的连线。
  · **每次下载必须冷启动**：点“编译下载”后出现“是否连接设备 ASR-PRO”时需给模块重新上电
    （经典做法为拔插 GND 5 秒）才会继续握手。
  · pin13 PA4 = PG_EN，上电高电平启动编程；默认 T+U(上拉)，**不可硬接地**。
  · PA4 另有复用：天问Block 生成代码会把 PA4 当 GPIO 用。
- 发现的 2 个设计缺口（已写入文档“硬件前提”）：
  · 【必须补】ASRPRO 烧录排针 J4（4pin：5V/GND/PB6/PB5）—— 现设计只引了 UART1，UART0 未引出 → 板焊好后无法烧 ASRPRO。
  · 【强烈建议】ASRPRO 5V 支路串 2pin 跳线 JP1 —— 否则“冷启动”要拔 GND = 整板断电。
  · 【可选】ESP32 自动下载电路（2×S8050 + 2×10k，J1 扩展为 8pin 接 DTR/RTS）。
- ESP32 烧录：USB-TTL ↔ J1（TXD→RXD0 pin34 / RXD→TXD0 pin35 / GND 共地 / 不接 3V3）；
  手动进下载模式 = 按住 SW1 → 短接 EN → 松手；命令 idf.py set-target esp32 / menuconfig / build / -p COM3 flash monitor
  （不稳定加 -b 115200）。
- 供电铁律：Type-C 供电与 USB-TTL 供电**只能接一路**（否则反灌 SY8089 输出）；USB-TTL 必须 3.3V 电平。
- 已知坑：Kconfig 默认 TX=18/RX=19，但 main/asr_pro.c 兜底宏为 16/17，README §5.5 残留 GPIO16 旧描述
  → 联调时以 menuconfig 生效值为准，改引脚后必须重新 build。
